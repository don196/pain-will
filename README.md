# Полигон подземелья — «Боль и Воля»

Тестовое поле боевой системы для тёмной фэнтези-НРИ (ориентиры — Fear & Hunger и Darkest Dungeon). На гексовом поле герои дерутся с болванчиками, а правила проверяются руками и тысячами симулированных боёв.

**Сайт:** https://don196.github.io/pain-will/ — обновляется сам после каждого изменения в `main`.

Сайт — одна статическая страница без сервера. Настройки правил и правки бойцов хранятся в браузере каждого игрока.

Полигон считает только по текущей системе: 3 ОД, Стойкость вместо пассивной защиты, Боль вместо HP. Прежняя версия со всеми старыми режимами (HP, 2 ОД, система от 12.11, старые герои и противники) лежит в ветке `legacy`.

## Как устроен код

TypeScript, модули по смыслу. Главное правило: **правила не знают про экран.** Всё в `rules/`, `ai/`, `data/` работает без браузера. Когда правилам нужно что-то показать (перерисовать поле, всплывающую цифру, спросить игрока), они зовут `view` из `src/view.ts`, а интерфейс при запуске подставляет туда свои функции. Поэтому тот же код гоняет и страница, и симулятор.

| Путь | Что там |
|---|---|
| `src/types.ts` | Модель данных: боец, шаблон, действие, рана, состояние боя. |
| `src/data/` | Свод: `actions` — оружие и способности, `fighters` — герои и противники, `scenarios` — карты, `disorders` — расстройства, `labels` — подписи. |
| `src/rules/` | Правила. `attack` — разрешение атаки; `pain` — Боль, броня, «на пороге»; `reactions` — 3 ОД, Стойкость, пороги промаха, «Прикрыть союзника»; `combat` — состояния, защита, толчок, подготовка, приказы; `magic`, `lasso`, `wounds`, `damage`, `disorders`; `actions` — выполнение действий и выбор целей; `turns` — ходы и раунды; `geometry`, `light` — гексы, линия видимости, свет. |
| `src/ai/ai.ts` | ИИ героев и болванчиков. |
| `src/state.ts`, `src/settings.ts` | Состояние боя и настройки из окна «Правила». |
| `src/ui/` | Интерфейс: `board` — поле и фигуры, `panels` — панели и лист бойца, `ctxmenu`, `input`, `modals`, `sim` — окна симуляции и шансов, `editor` — редактор поля, `data-editor` — «Бойцы и оружие». |
| `src/main.ts` | Запуск: связывает интерфейс с правилами. |
| `src/sim/cli.ts` | Симулятор для Node. |
| `src/debug.ts` | Объект `P` в консоли браузера: `P.S` — состояние боя, `P.perform(...)` — любое действие, `P.SET` — настройки. |
| `src/index.html`, `src/styles.css` | Разметка и стили страницы. |
| `build/build.mjs` | Сборка в `dist/index.html` (одна страница) и `dist/sim.cjs` (симулятор). |
| `sim/run.mjs` | Таблица баланса по сценариям. |
| `tests/smoke.mjs` | Проверки в браузере на компьютере и телефоне. |

Типы пока мягкие (`strict` выключен): описаны модель данных и основные параметры, остальное `any`. Ужесточать можно по модулю.

## Запуск у себя

Нужны Node.js 20+ и Python 3 (только для `npm run serve`).

```bash
npm ci                 # один раз
npm run build          # dist/index.html и dist/sim.cjs
npm run serve          # http://localhost:8000
```

Можно и просто открыть `dist/index.html` в браузере.

## Как вносить изменения

1. Заведи ветку, поправь файлы в `src/`.
2. Проверь у себя:
   ```bash
   npm run typecheck                 # типы
   npm run build
   npx playwright install chromium   # один раз
   npm test                          # проверки в браузере
   npm run sim                       # таблица баланса, по 200 боёв на сценарий
   npm run format                    # оформление кода (Prettier)
   ```
3. Открой пулл-реквест. GitHub проверит типы, соберёт страницу, прогонит проверки и положит таблицу баланса во вкладку **Actions → запуск → Summary**: сразу видно, сдвинула ли правка проценты побед.
4. После слияния в `main` сайт обновится примерно через пару минут.

**Переделка без изменения правил.** Симулятор умеет повторять бои один в один: одинаковое зерно — одинаковый бой. Сними подписи боёв до правки и сравни после:

```bash
npm run build && npm run -s golden -- dummies 300 > /tmp/before.txt
# … правка …
npm run build && npm run -s golden -- dummies 300 | diff /tmp/before.txt - && echo "бои те же"
```

## Симуляции

```bash
npm run sim -- --n 600                          # точнее, дольше
npm run sim -- --scn dummies6                   # один сценарий
npm run sim -- --set '{"dexMode":"od"}'          # с другой настройкой из окна «Правила»
node dist/sim.cjs batch '{"scn":"dummies","n":300}'   # сырой JSON
```

Текст правил ведётся отдельно, у автора.
